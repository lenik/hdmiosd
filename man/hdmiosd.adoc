== Name

hdmiosd - on-screen DDC/CI controller for HDMI/DP displays

== Synopsis

*hdmiosd* [_OPTION_]...

== Description

*hdmiosd* finds monitors that speak DDC/CI on Linux I2C buses and opens a
wxWidgets canvas OSD.

Two OSD areas are provided:

*Device menus* (Brightness, Image, Color, Audio, *OSD*, Presets, Misc)::
  Control the monitor via VCP. Empty categories (for example Audio with no
  supported codes) stay hidden. The *OSD* tab adjusts the monitor's own OSD
  language / button control when supported.

*App OSD*::
  Control the hdmiosd window: opacity, size, and edge margins.
  Values are written to *~/.config/hdmiosd/settings.ini* together with the
  last selected display and custom keyboard shortcuts.

Communication is implemented directly over */dev/i2c-** (no *ddcutil*
subprocess). Tabler icons are embedded in the binary via bas-cpp zip assets.

Access to I2C devices usually requires membership in the *i2c* group (or
root).

== Options

*-d, --device* _DEV_::
  Restrict discovery to buses related to _DEV_.

*-o, --opacity* _NUM_::
  Window opacity from *0* to *100* (overrides settings for this run).

*-g, --geom* _W_[x_H_]::
  Window size.

*-l, --left* / *-r, --right* / *-t, --top* / *-b, --bottom* _NUM_::
  Place the window _NUM_ pixels from that screen edge.

*-L, --list*::
  List DDC-capable displays and exit.

*-v, --verbose* / *-q, --quiet* / *-h, --help* / *--version*::
  Logging, help, version.

== Files

*~/.config/hdmiosd/settings.ini*::
  *[display]* last selected bus/connector;
  *[app_osd]* opacity, geometry, margins;
  *[shortcuts]* action to key mappings.
