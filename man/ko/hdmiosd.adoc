== 이름

hdmiosd - HDMI/DP 디스플레이용 DDC/CI OSD 컨트롤러

== 개요

*hdmiosd* [_OPTION_]...

== 설명

*hdmiosd* 는 Linux I2C 버스에서 DDC/CI 모니터를 찾아 wxWidgets 캔버스
OSD 를 엽니다.

OSD 영역은 두 가지입니다:

*장치 메뉴* (밝기, 이미지, 색상, 오디오, *OSD*, 프리셋, 기타)::
  VCP 로 모니터를 제어합니다. 빈 범주(지원 코드가 없는 오디오 등)는
  숨겨집니다. *OSD* 탭은 지원 시 모니터 자체 OSD(언어/버튼)를 조정합니다.

*App OSD*::
  hdmiosd 창(불투명도, 크기, 여백)을 제어합니다.
  값은 마지막으로 선택한 디스플레이 및 단축키와 함께
  *~/.config/hdmiosd/settings.ini* 에 저장됩니다.

통신은 */dev/i2c-** 로 직접 이루어지며(*ddcutil* 하위 프로세스 없음)
Tabler 아이콘은 bas-cpp zip 자산으로 포함됩니다.

I2C 접근에는 보통 *i2c* 그룹(또는 root)이 필요합니다.

== 옵션

*-d, --device* _DEV_::
  _DEV_ 관련 버스만 검색합니다.

*-o, --opacity* _NUM_::
  창 불투명도 *0*–*100* (이번 실행 설정 덮어씀).

*-g, --geom* _W_[x_H_]::
  창 크기.

*-l, --left* / *-r, --right* / *-t, --top* / *-b, --bottom* _NUM_::
  지정한 화면 가장에서 _NUM_ 픽셀 위치에 둡니다.

*-L, --list*::
  DDC 디스플레이를 나열하고 종료합니다.

*-v, --verbose* / *-q, --quiet* / *-h, --help* / *--version*::
  로그, 도움말, 버전.

== 파일

*~/.config/hdmiosd/settings.ini*::
  *[display]* 마지막 버스/커넥터;
  *[app_osd]* 불투명도, 기하, 여백;
  *[shortcuts]* 동작→키 매핑.
